# 序言

> **CodeFuse-Query** 是蚂蚁集团开源的一款**以数据为中心的静态代码分析系统**（ICSE 2025 相关论文：*Datalog-Based Language-Agnostic Change Impact Analysis for Microservices*）。它不是又一个"规则扫描器"，而是一个把"代码分析"重新定义为"数据计算"的平台：用语言抽取器（Extractor）把源代码转化为结构化的 COREF 代码数据（关系表/事实），再用声明式的 Gödel 查询语言在数据上推导出分析结论。

这套文档基于对 GitHub 开源仓库 `codefuse-ai/CodeFuse-Query` 的源码级深入分析编写，分为三部分：

| 部分 | 面向读者 | 内容 |
| --- | --- | --- |
| **入门级指南** | 第一次接触的研发、测试、安全工程师 | 安装、核心概念、第一个查询、CLI 使用、典型示例 |
| **进阶级指南** | 需要深入建模、写复杂分析、做二次开发的工程师 | Gödel 语言全量语法、COREF 模型、C/C++ 抽取器源码、性能调优、打包分发、引擎内部（Soufflé） |
| **专项评估** | 电信/嵌入式 C/C++ 大型代码仓负责人与架构师 | 千万行级 C/C++ 电信系统适用性评估（含结论与风险清单） |

## 这套系统解决什么问题？

传统静态分析工具（Clang Static Analyzer、PMD、SonarQube 等）通常是"工具中心"的：为某个特定目标定制。而 CodeFuse-Query 的核心主张是：

> 把**源代码**和**分析结果**都当作**数据**，把**分析过程**当作**大数据处理**。

由此带来三个直接收益：

1. **多语言统一建模**：Java / JS / TS / Go / C++ / Python / Swift / SQL / XML 等 11 种语言都被抽取到统一的 COREF 关系模型，一套查询语言通吃。
2. **声明式查询**：用户用 Gödel（一种 Datalog 方言）描述"要什么"，引擎自动做递归推导、图遍历、多表联结，不需要写命令式遍历代码。
3. **可扩展的数据平台**：与数据仓库、对象存储、K8s 等大数据基础设施无缝衔接，支持增量抽取、代码变更分析、CI 卡点、LLM 训练数据清洗等企业级场景。
